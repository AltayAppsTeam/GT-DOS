# GT-DOS
GT-DOS is a DOS-based operating system; it is simple, fast, and highly minimalist. It utilizes a terminal-based interface where you enter commands into a command line on the screen. You can use the "help" command to view available commands.

HOW TO INSTALL GT-DOS

STEP 1
First, you need either a computer with MS-DOS or FreeDOS installed, or a USB flash drive with MS-DOS or FreeDOS installed. If you already have a computer with MS-DOS or FreeDOS, proceed to Step 3. If you do not have such a computer but possess a USB flash drive with DOS installed, proceed to Step 2. If you have neither, but you do have an empty or unused USB flash drive, continue reading.
To install DOS onto a USB flash drive, you can use the Rufus software. In Rufus, select "FreeDOS" or "MS-DOS" (either is fine) under the "Boot selection" option. Ensure that "MBR" is selected under the "Partition scheme" option. (WARNING: PERFORMING THIS PROCESS WILL ERASE ALL FILES ON YOUR USB FLASH DRIVE. IF YOUR USB DRIVE CONTAINS IMPORTANT FILES OR DATA, DO NOT USE IT, OR BACK UP THE DATA TO YOUR COMPUTER FIRST.) You may then assign a name to the USB drive and click "Start" to begin the installation. Once the process is complete, verify that the installation was successful by checking the contents of the USB drive; if several files have been created on it, the installation was successful. Next, go to the "Releases" section of this GitHub repository and download the "GT-CALC.EXE", "GT-DOS.EXE", and "GT-FILES.EXE" files. Move or copy these downloaded files into the root directory of your USB flash drive. Then, shut down your computer completely.
STEP 2
Once these steps are complete, access your computer's Boot Menu—don't worry, finding it is quite simple! Typically, you can open the Boot Menu by repeatedly pressing a specific key immediately after pressing the power button. If you aren't sure which key to use, you can search for your computer's brand online or ask an AI by providing your computer's brand to find out how to access the Boot Menu. Once you have successfully opened the Boot Menu, a list of selectable options will appear on the screen; you should see the name or brand of your USB flash drive. Select it and press Enter to boot from the USB drive. You should then see a "C:\" prompt on the screen—if you see it, you're all set!
STEP 3
Finally, type "GT-DOS" and press Enter; GT-DOS will launch! Feel free to use it as you wish. To exit GT-DOS, type "exit," and to turn off the system, press and hold the power button. You will need to repeat Step 3 each time you wish to enter GT-DOS.

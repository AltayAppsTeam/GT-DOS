HOW TO INSTALL GT-DOS

First, you will need an empty USB flash drive. Once you have one, install the Rufus program and select either FreeDOS or MS-DOS under the "Boot Selection" option—it does not matter which one you choose. (WARNING: Clicking "Start" will erase everything on the USB flash drive.) Click the "START" button. Once the process is successfully completed, download the all "GT" files and GT-DOS from the "Releases" section of this repository and place them in the root directory of your USB flash drive. Shut down your computer and ensure the USB flash drive is plugged in. Next, search online for the key used to access the boot menu for your specific computer brand. Once you have identified the correct key, press the power button on your computer and immediately begin tapping that key. A menu will appear; select your USB flash drive and press Enter. You will then see a command prompt displaying `C:\`. Type "GT-DOS" at this prompt, and GT-DOS will launch!
